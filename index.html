Lab Overview

Welcome to this hands-on lab for ACME Corporation, a global company specializing in the sale of widgets worldwide. In this lab, you will build the core IT infrastructure for ACME by installing and configuring Windows Server 2019 Essentials on a Dell computer, promoting it to a Domain Controller, configuring it as a File Server, and managing users and permissions for three departments.

Learning Objectives

Upon completing this lab, you will be able to:

  • Install Windows Server 2019 Essentials on a Dell computer
  • Configure a new Active Directory domain (172.16.100.x / ACME.LOCAL)
  • Join three Windows client computers to the domain
  • Create and configure domain user accounts with a standard naming convention
  • Create and share department folders with appropriate drive letter mappings
  • Apply NTFS permissions to restrict access between departments
  • Create sub-folders within each department share and assign Modify permissions

Lab Topology

Your lab environment consists of the following machines:

Set static IP addresses on all machines. The Domain Controller must have its own IP as the preferred DNS server.

Part 1 — Installing Windows Server 2019 Essentials

In this part, you will boot your Dell computer from the Windows Server 2019 Essentials installation media and complete the initial OS setup.

1.1 Pre-Installation Checklist

Before starting the installation, verify the following:

  • Dell computer is powered off
  • Windows Server 2019 Essentials ISO is burned to a bootable USB drive (use Rufus or the Windows USB/DVD Download Tool)
  • Computer BIOS/UEFI is configured to boot from USB first
  • The Dell computer has at least 2 GB RAM and 32 GB storage (64 GB recommended)
  • You have noted the product key for Windows Server 2019 Essentials

1.2 Installation Steps

  1. Insert the bootable USB drive into the Dell computer and power it on.
  2. When prompted, press any key to boot from USB.
  3. In the Windows Setup window, select your preferred Language, Time format, and Keyboard layout, then click Next.
  4. Click Install now.
  5. Enter your product key when prompted, then click Next. (If you are using an evaluation copy, click I don't have a product key)
  6. Select Windows Server 2019 Essentials (Desktop Experience) and click Next.
  7. Accept the license terms and click Next.
  8. Click Custom: Install Windows only (advanced).
  9. Select the target disk (usually Drive 0 Unallocated Space) and click New, then Apply, then Next. Windows will create the required partitions automatically.
  10. The system will copy files and restart several times. This process takes approximately 15–25 minutes.
  11. After the final restart, you will be asked to set the Administrator password. Use a strong password. Example: Acme@2024! (do NOT use this in production)
  12. Press Ctrl+Alt+Delete and log in with the password you just created.

⚠️ Important:
Record the Administrator password in a secure location. You will need it throughout this lab.
Do not use simple passwords such as 'Password123' — Windows Server enforces complexity requirements.

1.3 Post-Installation — Set Static IP Address

Before promoting the server to a Domain Controller, assign a static IP address.

  1. Open Server Manager (it opens automatically after login).
  2. Click Local Server in the left panel, then click the link next to Ethernet.
  3. Right-click your network adapter and choose Properties.
  4. Select Internet Protocol Version 4 (TCP/IPv4) and click Properties.
  5. Select Use the following IP address and enter:
Setting Value
IP Address 172.16.100.10
Subnet Mask 255.255.255.0
Default Gateway 172.16.100.1
Preferred DNS Server 172.16.100.10
Alternate DNS Server (leave blank for now)
  1. Click OK twice, then close the Network Connections window.
  2. Rename the server: In Server Manager, click Local Server, then click the current computer name. Change it to DC01, click OK, and restart when prompted.

Part 2 — Promoting the Server to a Domain Controller

Now you will install the Active Directory Domain Services (AD DS) role and promote DC01 to a Domain Controller for the new ACME.LOCAL domain.

2.1 Install the AD DS Role

  1. In Server Manager, click Manage → Add Roles and Features.
  2. Click Next on the Before you begin page.
  3. Select Role-based or feature-based installation and click Next.
  4. Confirm DC01 is selected as the destination server. Click Next.
  5. In the Server Roles list, check Active Directory Domain Services. A dialog will appear — click Add Features, then click Next.
  6. Click Next on the Features page (no additional features needed).
  7. Click Next on the AD DS information page.
  8. Click Install. Wait for the installation to complete (approximately 3–5 minutes).
  9. When installation finishes, click Close. Do NOT restart yet.

2.2 Promote to Domain Controller

  1. In Server Manager, click the yellow flag notification icon (top right) and click Promote this server to a domain controller.
  2. Select Add a new forest and enter the root domain name: acme.local
  3. Click Next.
  4. On Domain Controller Options: verify Forest functional level and Domain functional level are both set to Windows Server 2016 (or 2019 if available). Leave DNS Server and Global Catalog checked.
  5. Enter and confirm the Directory Services Restore Mode (DSRM) password. Example: Dsrm@2024!
  6. Click Next through the DNS Delegation warning (click Next to skip).
  7. The NetBIOS domain name should auto-populate as ACME. Click Next.
  8. Accept the default paths for Database, Log files, and SYSVOL. Click Next.
  9. Review the summary on the Review Options page. Click Next.
  10. On Prerequisites Check: ignore any warnings about DNS delegation. Click Install.
  11. The server will install AD DS and restart automatically. This process takes 5–10 minutes.
  12. After the restart, log in as ACME\Administrator (or use Administrator if only one account is shown).

📝 Note:
After promotion, your server is now a Domain Controller. Server Manager will show 'AD DS' and 'DNS' in the left panel.
Verify the domain is working: Open a Command Prompt and type: nslookup acme.local
The response should show the IP address 172.16.100.10.

Part 3 — Joining Client Computers to the Domain

Perform the following steps on each of the three client computers (PC01, PC02, PC03). Each client must be running Windows 10 or Windows 11 Professional.

3.1 Configure Client Network Settings

On each client computer, set the IP address and DNS server before joining the domain. Use the values in the table below:

Computer IP Address Subnet Mask Gateway DNS Server
PC01 172.16.100.21 255.255.255.0 172.16.100.1 172.16.100.10
PC02 172.16.100.22 255.255.255.0 172.16.100.1 172.16.100.10
PC03 172.16.100.23 255.255.255.0 172.16.100.1 172.16.100.10

To set the static IP on each client:

  1. Right-click the network icon in the System Tray → Open Network & Internet Settings.
  2. Click Change adapter options.
  3. Right-click the active adapter → Properties.
  4. Select IPv4 → Properties, then enter the values from the table above.
  5. Set Preferred DNS to 172.16.100.10 (the Domain Controller's IP).
  6. Click OK to save, then close all windows.
  7. Test connectivity: Open Command Prompt and type: ping 172.16.100.10. You should receive 4 replies.

3.2 Join the Computer to the Domain

  1. Right-click the Start button → System.
  2. Scroll down and click Rename this PC (advanced).
  3. In the System Properties window, click Change.
  4. Under Computer name, enter the computer name (PC01, PC02, or PC03 as appropriate).
  5. Under Member of, select Domain and type: acme.local
  6. Click OK.
  7. When prompted for credentials, enter:
    • Username: ACME\Administrator
    • Password: (the Administrator password set during server installation)
  8. Click OK. You will see a Welcome to the acme.local domain message.
  9. Click OK, then click OK again on the restart prompt.
  10. Restart the computer.
  11. After restart, click Other user and log in with a domain account to verify.

⚠️ Important:
Repeat Steps 3.1 and 3.2 on PC02 and PC03 before continuing.
All three computers must be joined to the domain before proceeding to Part 4.

  4. For each user in the table above, fill in the New Object — User dialog as follows:

4.3 Create Organizational Units (Optional but Recommended)

For better organization, create Organizational Units (OUs) for each department:

  1. In Active Directory Users and Computers, right-click acme.local → New → Organizational Unit.
  2. Name it Sales. Click OK.
  3. Repeat to create Marketing and HR organizational units.
  4. Move each user to their respective OU: right-click the user → Move → select the appropriate OU.

Part 5 — Configuring the File Server and Department Shares

DC01 will act as the file server for ACME. You will install the File Server role, create department folders, configure NTFS permissions, and create hidden shared folders (using the $ suffix) that map to drive letters for each department.

5.1 Install the File and Storage Services Role

  1. In Server Manager, click Manage → Add Roles and Features.
  2. Proceed through the wizard until Server Roles. Expand File and Storage Services → File and iSCSI Services.
  3. Check File Server and File Server Resource Manager. Click Add Features if prompted.
  4. Click Next through remaining pages and click Install.
  5. Wait for installation to complete. No restart is required.

5.2 Create Department Folders

You will create the department folders in C:\DeptShares\ on DC01.

  1. Open File Explorer on DC01.
  2. Navigate to Local Disk (C:).
  3. Create a new folder named DeptShares.
  4. Inside DeptShares, create three sub-folders:
    • Sales
    • Marketing
    • HR

📝 Note:
Your folder structure should look like this:
C:\DeptShares\Sales\
C:\DeptShares\Marketing\
C:\DeptShares\HR\

5.3 Create Sub-Folders Inside Each Department Folder

In each department folder, create 2 sub-folders. Suggested names are provided below (you may use your own naming):

Department Folder Sub-Folder 1 Sub-Folder 2 Drive Letter
C:\DeptShares\Sales Contracts Leads S:
C:\DeptShares\Marketing Campaigns Assets M:
C:\DeptShares\HR Onboarding Payroll H:

To create sub-folders:

  1. Open the Sales folder (C:\DeptShares\Sales).
  2. Right-click in an empty area → New → Folder. Name it Contracts.
  3. Repeat to create the Leads folder.
  4. Repeat for Marketing (Campaigns, Assets) and HR (Onboarding, Payroll).

5.4 Create Domain Local Security Groups

Create a security group for each department to manage permissions centrally:

  1. Open Active Directory Users and Computers.
  2. Right-click the Users container (or the department OU) → New → Group.
  3. For the Sales group:
    • Group name: GRP_Sales
    • Group scope: Domain Local
    • Group type: Security
    • Click OK
  4. Repeat to create GRP_Marketing and GRP_HR.
  5. Add users to their groups:
    • Double-click GRP_Sales → Members tab → Add → type jsmith → OK. Repeat for mgonzalez.
    • Double-click GRP_Marketing → Members tab → Add → aparker, dlee.
    • Double-click GRP_HR → Members tab → Add → sturner.

5.5 Configure NTFS Permissions

Now configure NTFS permissions so that only the appropriate group can access each folder. You will remove broad permissions and apply department-specific access.

Perform the following steps for EACH department folder (Sales, Marketing, HR):

Example: Configuring NTFS Permissions for the Sales Folder

  1. Right-click C:\DeptShares\Sales → Properties.
  2. Click the Security tab → Advanced.
  3. Click Disable inheritance. When prompted, choose Convert inherited permissions into explicit permissions on this object.
  4. Back in the Advanced Security Settings, remove Users (ACME\Users) from the list (select it → Remove).
  5. Click Add → Select a principal. Type GRP_Sales → OK.
  6. Set Type to Allow. Check Modify, Read & execute, List folder contents, Read, Write.
  7. Click OK → Apply → OK.

Repeat the same steps for Marketing (using GRP_Marketing) and HR (using GRP_HR).

⚠️ Important:
Make sure to also set the same Modify permissions on the two sub-folders within each department folder.
Verify that SYSTEM and Administrators still have Full Control — do not remove those entries.
The goal is: Sales users can only access Sales; Marketing users only Marketing; HR only HR.

5.6 Create and Share the Department Folders

Create hidden shares (using $ suffix) so only mapped drive users can connect directly:

For each department folder, do the following (example for Sales):

  1. Right-click C:\DeptShares\Sales → Properties → Sharing tab → Advanced Sharing.
  2. Check Share this folder.
  3. Enter the share name: Sales$ (the $ makes it hidden).
  4. Click Permissions. Remove Everyone. Add GRP_Sales with Change permission (which grants read and write). Click OK.
  5. Click OK → Close.
Folder Path Share Name Share Permission UNC Path
C:\DeptShares\Sales Sales$ GRP_Sales — Change \\DC01\Sales$
C:\DeptShares\Marketing Marketing$ GRP_Marketing — Change \\DC01\Marketing$
C:\DeptShares\HR HR$ GRP_HR — Change \\DC01\HR$

Part 6 — Mapping Department Drive Letters via Group Policy

In this final configuration step, you will use Group Policy to automatically map the correct drive letter for each user when they log in to any domain computer. This ensures Sales users see S:, Marketing users see M:, and HR users see H: automatically.

6.1 Open Group Policy Management

  1. On DC01, open Server Manager → Tools → Group Policy Management.
  2. Expand Forest: acme.local → Domains → acme.local.
  3. Right-click Group Policy Objects → New.
  4. Name the GPO: Drive Mappings — ACME. Click OK.
  5. Right-click the new GPO → Edit. The Group Policy Management Editor will open.

6.2 Create Drive Mappings for Each Department

In the Group Policy Management Editor, navigate to:
User Configuration → Preferences → Windows Settings → Drive Maps

Right-click Drive Maps → New → Mapped Drive.

Configure the Sales drive mapping:

  • Action: Create
  • Location: \\DC01\Sales$
  • Label as: Sales Drive
  • Drive Letter: S
  • Click the Common tab → check 'Item-level targeting' → Targeting → New Item → Security Group → select GRP_Sales
  • Click OK

Repeat for Marketing and HR:

Department UNC Path Drive Letter Label Target Group
Sales \\DC01\Sales$ S: Sales Drive GRP_Sales
Marketing \\DC01\Marketing$ M: Marketing Drive GRP_Marketing
HR \\DC01\HR$ H: HR Drive GRP_HR

6.3 Link the GPO to the Domain

  1. In Group Policy Management, right-click acme.local → Link an Existing GPO.
  2. Select Drive Mappings — ACME → OK.
  3. To force Group Policy to apply immediately (instead of waiting up to 90 minutes), on DC01 open Command Prompt and type: gpupdate /force
  4. Log off and log back on from a client computer as one of the domain users to verify the drive letter appears.
